아는 내용을 넣고 확인한 뒤 저장하면 됩니다. 모르는 것은 작성 중으로 남겨도 괜찮습니다.

처음 설치와 본인 계정 준비는 아들과 함께 확인하세요.

1.0.0용 사용 안내입니다. 설치 파일의 버전과 공식 배포 안내를 확인하세요. 어머니 컴퓨터에서 첫 견적을 저장하고 다시 열어 본 뒤 사용합니다.

견적·계획 만들기AI 초안 부탁하기전체 백업하기

1. 먼저 설치하고 앱을 켜세요

  1. 검증된 설치 ZIP을 새 폴더에 모두 압축 풀기로 풉니다.
  2. 풀린 폴더의 맨 위에 있는 INSTALL.cmd를 두 번 누릅니다.
  3. 설치 완료 안내를 확인합니다.
  4. 바탕화면의 아로마 업무 도우미를 엽니다.
  5. 첫 화면의 큰 견적서 만들기를 누릅니다.

다음부터는 바탕화면 바로가기로 켜면 됩니다. 바로가기가 없으면 아들과 설치 폴더의 aroma_app\START_APP.cmd를 확인하세요.

첫 설치에는 수업 목록이 비어 있습니다. 아들과 이번에 사용할 프로그램을 확인해 준비하세요.

설치나 시작이 안 되면 오류 문구를 아들에게 알려 주세요. 기존 자료를 지우거나 설치·로그인을 반복하지 마세요.

처음 설정 자세히

2. 이번 의뢰와 금액을 적으세요

의뢰 내용 → 프로그램 → 내용 입력 → 마지막 확인 → 미리보기

  • 이번 기관·참여 인원과 알고 있는 날짜·시간을 넣습니다.
  • 이번 수업에 맞는 프로그램을 고릅니다.
  • 재료 수량·단가·강사비·출장비·할인·세금 방식을 확인합니다.
  • 인원마다 늘어나는 재료와 한 번만 준비하는 공용 재료를 구분합니다.

모르는 가격을 임의의 0원으로 채우지 마세요. 지난 자료의 금액·시간을 이번 승인 값으로 생각하지 않습니다.

3. 한 번 더 보고 저장하세요

기관·인원·프로그램·날짜·시간·금액·세금을 다시 확인합니다.

확인한 내용은 확인하고 저장하기, 아직 모르는 내용이 있으면 아직 확인 전·작성 중으로 저장을 누릅니다.

컴퓨터에 저장됐다는 안내를 확인하세요. ‘브라우저에 임시 보관 중’이면 실행과 저장 상태를 먼저 확인합니다.

계획서가 필요하면 첫 화면에서 계획서 만들기를 고르고 이번 목표·진행·준비물을 적습니다. 만드는 것만으로 예약이나 고객 발송이 되지는 않습니다.

4. 글 초안이 필요할 때만 AI를 쓰세요

견적 계산·계획·저장은 이 컴퓨터에서 합니다. 글이 필요하면 초안 도우미 → Codex로 초안 만들기를 선택합니다.

  1. 제목·목적·대상·직접 확인한 내용을 넣습니다.
  2. 보낼 항목을 고르고 보낼 내용 미리보기를 봅니다.
  3. 보내면 안 되는 내용이 없는지 확인합니다.
  4. 이번 전송에 동의한 뒤 이 내용으로 초안 요청하기를 누릅니다.

전화번호·이메일은 기본 제외합니다. 자료 파일·경로·사진을 자동으로 보내지 않습니다. 고객 자료를 보내기 전에는 필요한 범위를 직접 확인하세요.

본인 공식 계정의 정상 로그인이 필요합니다. 이미 정상 로그인돼 있으면 그대로 사용합니다. 앱을 켜는 것만으로 새 로그인이나 AI 요청을 하지 않습니다. 실패·취소 뒤 자동으로 다시 요청하지 않습니다. 계정 사용 한도를 쓰며 중단해도 사용량이 돌아온다고 보장하지 않습니다.

5. 받은 글 전체를 고치고 파일로 만드세요

AI 글의 제목·요약·각 문장·확인사항·주의사항을 모두 봅니다. 틀린 사실과 공개하면 안 되는 내용은 고칩니다.

  1. AI 내용 전체로 PPTX 또는 Word 문서 버튼을 고릅니다.
  2. 모든 항목을 읽고 수정합니다.
  3. 수정한 전체 내용 미리보기를 누릅니다.
  4. 현재 수정본을 확인하는 칸을 체크합니다.
  5. PPTX 파일 저장 또는 DOCX 파일 저장을 누릅니다.

PPT는 문장 8개를 8장에, Word는 항목 3개를 3쪽에 넣는 형식입니다. 글이 길거나 문장 수가 맞지 않으면 수정 안내가 나옵니다. 내용을 몰래 버리거나 글씨를 줄이지 않습니다.

원래 AI 글은 기록에 남고 파일에는 확인한 수정본을 넣습니다. 파일 출력은 새 AI 요청을 보내지 않습니다. 발표 구성안을 Word로 바꾸어도 새 보고서를 AI에 요청한 것은 아닙니다.

Word·PowerPoint 또는 호환 프로그램으로 파일을 열어 한글·쪽수·슬라이드·수치·빈 사진 자리를 확인하세요. 미리보기와 실제 파일의 배치는 다를 수 있습니다.

6. 홍보 서식과 AI 그림을 받으세요

홍보 서식은 초안 도우미에서 홍보물 문구와 배치를 고릅니다. 제목·대상·프로그램·날짜·시간·장소·비용·문의 내용을 확인한 뒤 서식 초안을 만듭니다.

홍보 PNG 다운로드를 누르고 앱 저장 완료 안내 뒤 파일을 받습니다. 입력한 글자를 배치하는 서식이며 사진 자리는 비워 둡니다.

AI로 새 그림이 필요하면 따로 요청합니다. 홍보 글자 서식과 새 그림 파일은 별개입니다.

  1. 연결·관리 → 이미지 요청 준비를 엽니다.
  2. 만들 그림을 짧게 설명합니다.
  3. 보낼 내용 미리보기를 읽고 이번 전송에 동의합니다.
  4. 이번 이미지 요청하기를 누릅니다.
  5. 완료 안내 뒤 PNG 이미지 내려받기로 받습니다.

사진을 올려 바꾸기나 여러 장 만들기는 지원하지 않습니다. 받은 그림은 문서·PPT에 자동으로 들어가지 않습니다. 아들과 편집 프로그램에서 직접 넣고 완성 파일을 확인하세요.

그림과 글은 보내기 전 직접 열어 보고 사용 권리를 확인합니다. 앱에 저장된 홍보 서식과 AI 그림은 전체 업무 백업에 들어갑니다. 실패·취소해도 자동으로 다시 요청하지 않으며 계정 사용량이 돌아온다고 보장하지 않습니다.

7. 저장한 작업을 다시 여세요

저장한 작업에서 방금 만든 견적·계획을 다시 엽니다. 기관·날짜·합계를 확인합니다.

AI 결과는 연결·관리 → 이전 Codex 요청 보기에서 확인합니다.

출력물의 ‘확인 필요’ 내용·날짜·금액·사진 권리를 확인한 뒤 사용하세요. 앱이 고객에게 자동 발송하지 않습니다.

예전 자료를 가져오고 싶어요

자료 찾기 → 파일 선택해서 가져오기로 필요한 파일만 고릅니다.

원본은 그대로 두고 앱에 사본을 저장합니다. 저장 완료 뒤 이름으로 검색하고 저장한 사본 받기로 받습니다. 가져오기만으로 내용 분석·최신본 승인·AI 전송이 되지는 않습니다.

8. 전체 업무 백업을 보관하세요

  1. 작업이 컴퓨터에 저장됐는지 확인하고 진행 중인 AI 요청을 마칩니다.
  2. 연결·관리 → 전체 업무 백업·복구를 엽니다.
  3. 전체 백업 만들기를 누릅니다.
  4. 파일 확인 안내 뒤 ZIP 다운로드로 받습니다.
  5. 본인이 관리하는 다른 저장장치에도 복사합니다.

새 전체 백업은 문서·가져온 사본·AI 결과·앱 출력물·현재 프로그램 설정·자료 목록을 묶습니다. 이전 백업은 포함 범위가 다를 수 있으니 목록을 확인하세요. 원본·로그인·앱 밖에만 있는 파일은 따로 보관합니다.

백업에 고객 정보가 들어갈 수 있습니다. 공개 게시물이나 설치 파일에 넣지 마세요. 같은 컴퓨터의 사본만으로 기기 고장을 대비할 수는 없습니다.

백업에서 되돌리고 싶어요

현재 작업을 백업 날짜의 내용으로 바꾸는 기능입니다. 먼저 아들과 날짜·파일 이름·포함 범위를 확인합니다. 다른 장치에만 있는 백업은 아들이 앱의 현재 백업 위치에 준비한 뒤 목록을 확인하세요.

  1. 전체 백업 목록에서 이 백업으로 복구를 고릅니다.
  2. 이 컴퓨터의 관리자 PIN을 확인합니다.
  3. 바꿀 내용을 다시 확인하고 복구를 선택합니다.
  4. 완료 안내 뒤 문서·사본·AI 결과·출력물을 다시 엽니다.

현재 컴퓨터의 PIN은 유지합니다. 새 전체 백업은 프로그램 설정도 그때로 되돌리고 이전 전체 백업은 현재 설정을 유지할 수 있습니다. Codex 로그인은 복구하지 않습니다.

복구가 멈추거나 새 작업이 막혔어요

완료를 확인하지 못한 상태입니다. 같은 복구를 반복하거나 잠금 파일을 지우지 마세요. 자료와 안전 백업을 그대로 두고 오류 문구를 아들에게 알려 주세요.

앱 종료를 확인한 뒤 다시 켭니다. 중단 복구 안내가 있으면 관리자 PIN 확인 후 아들과 안전 백업으로 돌아갑니다. 이전 실행이 끝났는지 모르면 기다려야 합니다.

마칠 때는 연결·관리 → 앱 종료를 사용하세요. 브라우저 창만 닫으면 앱은 계속 켜져 있을 수 있습니다.
