# 아로마 업무 1.1.0 로컬 데이터 계약

업무 데이터 형식은 schema 2입니다. 견적·계획·자료 사본·AI 결과·출력물과 신청·주문·상품·일정을 로컬로 관리합니다. 관리자 기능은 PIN 확인과 앱 세션 검사를 거칩니다.

전체 백업 ZIP 가져오기는 검증한 로컬 사본만 만들며 기존 업무를 바꾸지 않습니다. schema 1은 원본을 보존한 새 schema 2 백업 사본으로 변환합니다. 실제 복원은 별도 확인, 안전 백업, 보관 사본 및 중단 복구 절차를 거칩니다. PIN과 로그인·외부 연동 인증은 업무 백업에서 제외합니다. 외부 Site 연동은 기본 미설정입니다.
