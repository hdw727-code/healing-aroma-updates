# 아로마 업무 · 1.1.0 사용 안내

## 1.0.1 자료를 1.1.0으로 가져오기

1.1.0은 신청·주문, 체험·상품, 일정과 문의 검색·상태별 목록을 포함한 별도 설치본입니다. 기존 1.0.1 업데이트 화면에서 자동 설치되지 않습니다. 이전 앱을 지우거나 덮어쓰지 않습니다.

1. 이전 1.0.1 앱에서 **연결·관리 → 전체 업무 백업·복구 → 전체 백업 만들기 → ZIP 다운로드**로 백업을 준비합니다. 원본 ZIP을 별도 저장장치에도 보관합니다.
2. 1.1.0 설치 ZIP 전체를 새 폴더에 풀고 최상위 `INSTALL.cmd`를 실행합니다. 새 기본 위치는 `%LOCALAPPDATA%\HealingAromaWork_1_1_0`이며 바탕화면의 **아로마 업무 도우미 1.1**로 엽니다. 기존 1.0.1 폴더와 바로가기를 보존합니다.
3. 새 앱에서 본인이 새 관리자 PIN을 정합니다. 이전 PIN·AI 로그인·외부 연동 인증은 가져오지 않습니다. AI를 쓰려면 새 앱에서 본인의 공식 로그인을 별도로 확인합니다.
4. **처음 화면 → 이전 앱 자료 가져오기** 또는 **연결·관리 → 전체 백업·이전 자료 가져오기**에서 이전 ZIP을 선택합니다. **선택한 백업 가져오기**는 검증한 사본만 만들며 현재 업무를 바꾸지 않습니다.
5. 목록에 **이전 자료 형식 · 변환 필요**가 표시되면 **새 형식 사본 만들기**를 누릅니다. 변환은 원본 ZIP을 보존하고 새로운 백업만 만듭니다.
6. 새 사본의 포함 범위를 확인한 뒤 **이 백업으로 복원 → 확인하고 전체 복원**을 선택합니다. 이 단계는 현재 1.1.0 업무를 백업 내용으로 바꾸므로 바꿀 자료를 직접 확인합니다. 복원 전 안전 백업과 자료 사본을 보관하며 새 앱의 PIN은 유지합니다.
7. 문서·사본·AI 결과·출력 파일·프로그램 목록을 열어 비교합니다. 확인을 마칠 때까지 이전 앱과 ZIP을 보관하고 두 앱의 업무를 각각 수정하지 않습니다.

전체 백업의 포함 범위(v1/v2)와 업무 데이터 형식(schema 1/2)은 서로 다른 표시입니다. 이전 포함 범위 v1 백업은 새 형식으로 변환해도 프로그램 설정·자료 목록을 새로 만들지 않으며 현재 설정을 유지합니다. 앱 밖에만 있는 파일과 원본 USB는 따로 보관합니다.

## 신청·주문 사용 범위

**신청·주문**에서 직접 기록한 문의를 접수·확인 중·처리 완료 등의 상태로 관리합니다. 기본 **해야 할 일**은 접수·확인 중이며 예약 취소는 제외합니다. 상태별 건수를 보고 상품·체험 이름이나 문의 번호로 검색합니다. 관리자 잠금을 누르면 검색어와 고객 내용도 화면에서 지웁니다. 실제 예약·금액·재고는 확인해서 입력합니다.

외부 신청 Site 연결은 아직 설정하지 않았습니다. 설치만으로 외부 사이트 문의가 들어오거나 어머니에게 알림이 전송되지 않습니다. 고객 발송·결제·예약 확정도 자동 실행하지 않습니다.

견적·계획·자료 사본·문서 출력·백업을 한 컴퓨터에서 관리하는 Windows용 앱입니다. 이 설치본은 빈 업무 자료로 시작합니다. 프로그램·가격·일정은 사용자가 확인해 입력합니다.

1.1.0용 사용 안내입니다. 설치 파일의 버전과 공식 배포 안내를 확인하세요. 처음 설치할 컴퓨터의 Windows 종류·본인 로그인·출력 프로그램·백업 장치는 아들과 함께 준비합니다. 이 안내는 특정 컴퓨터의 설치나 인터넷 업데이트가 이미 끝났다는 뜻은 아닙니다.

## 어디부터 읽나요?

- [어머니 첫 사용 안내](MOTHER_GUIDE.html): 큰 글씨로 견적 한 건부터 시작합니다.
- [처음 설정 안내](SETUP_GUIDE.md): 컴퓨터 조건·공식 계정·시작 문제를 확인합니다.
- [아들 운영 안내](SON_GUIDE.md): 전체 백업·복구·업데이트·비용을 관리합니다.
- [처음 실행 안내](START_HERE.html): 큰 글씨로 실행과 첫 작업 순서를 확인합니다.
- [포함된 빈 서식 안내](examples/README.md): [PPT 빈 서식](examples/lecture_example.pptx)과 [Word 빈 서식](examples/report_example.docx)의 용도를 확인합니다. 실제 내용은 앱에서 작성·검토해 새 파일로 만듭니다.

처음 설치할 때는 검증된 설치 ZIP을 새 폴더에 **모두 압축 해제**하고 최상위 `INSTALL.cmd`를 실행합니다. 현재 사용자 폴더의 `%LOCALAPPDATA%\HealingAromaWork_1_1_0`에 설치하며 관리자 권한이나 전역 설치를 요구하지 않습니다. 설치 완료 뒤 바탕화면의 **아로마 업무 도우미 1.1**를 엽니다. 바로가기가 없으면 설치 폴더의 `aroma_app\START_APP.cmd`를 직접 실행합니다. [START_APP.cmd](START_APP.cmd)는 앱 폴더에서 다시 시작할 때 사용합니다.

압축 파일 안에서 바로 실행하거나 기존 업무 폴더에 덮어쓰지 않습니다. 설치 대상이 이미 있으면 중단하며 기존 앱과 자료를 보존합니다. 설치만으로 앱·로그인·AI 요청·업데이트를 실행하지 않습니다. 처음에는 아들과 설치·시작·종료·재실행을 확인하세요.

## 사용할 수 있는 작업

| 작업 | 방식·확인할 점 |
|---|---|
| 견적·계획 | 확인한 인원·수량·단가·비용으로 계산하고 작성 중/확인 완료를 구분합니다. 날짜·가격·세금·안전 안내는 사용자가 확인합니다. |
| 저장·다시 열기 | 컴퓨터 저장 여부를 보고 저장 목록에서 다시 엽니다. 이력·복사·되돌리기로 작업을 이어갑니다. |
| 자료 가져오기 | 선택한 파일의 로컬 사본을 보관·검색·다운로드합니다. 원본을 바꾸지 않으며 가져오기만으로 내용 분석·최신본 판정·AI 전송을 하지 않습니다. |
| 선택 AI 텍스트 | 본인 공식 Codex 계정으로 보낼 항목·전체 미리보기·이번 동의를 확인한 뒤 요청합니다. 자동 요청·자동 재시도·파일 자동 전송은 없습니다. |
| 전체 AI 결과 편집 | 제목·요약·모든 문장·확인사항·주의사항을 검토·수정하고 정확한 현재 수정본을 확인합니다. 원래 결과는 로컬 기록에 유지합니다. |
| 문서 출력 | 지원 서식으로 DOCX 3쪽 또는 PPTX 8장을 만듭니다. 고정 분량·글자 한계를 넘으면 수정 안내를 표시하며 자동 절단하지 않습니다. 파일 생성에 Office·추가 AI 호출은 필요하지 않고 열기/편집 프로그램은 별도입니다. |
| 홍보 PNG | 입력한 글자를 배치하는 로컬 서식입니다. 앱에 먼저 저장하고 받으며 전체 업무 백업에 포함합니다. AI 사진·제품 사진 자동 삽입은 없습니다. |
| 선택 AI 그림 | 설명 미리보기·이번 동의 후 새 그림 한 장을 요청합니다. 앱에서 확인한 PNG를 저장·미리보기·다운로드하며 전체 업무 백업에 포함합니다. 문서·PPT·홍보물에 자동 삽입하지 않습니다. |
| 전체 백업 v2 | 문서 DB·가져온 사본·AI 결과·앱 출력물·현재 프로그램 설정·자료 목록을 묶습니다. 기본 압축 전 한도는 1 GiB·10,000개입니다. |

AI 없이 견적·계획·저장·로컬 서식 출력을 사용할 수 있습니다. AI 결과와 파일도 초안으로 확인하며 실제 일정·금액·효능·사진 권리를 사용자가 검토합니다. 고객 발송·예약·결제는 자동 실행하지 않습니다.

## 지원 조건과 현재 남은 확인

Windows 10/11 AMD64(x64: Intel/AMD 64비트) 공통 묶음입니다. Windows 10은 1809/build17763 이상이고 충분히 업데이트한 환경에서 best effort 조건입니다. 어머니 실제 PC·두 OS 전체 앱·편집기·프린터 확인은 별도로 필요합니다. macOS·32비트·ARM 지원은 제공하지 않습니다.

공식 실행 파일이 포함돼도 사용자 로그인과 계정 한도는 별개입니다. AI를 쓰려면 본인 정상 공식 로그인과 직접 전송 동의가 필요합니다. 로그인은 운영체제 자격증명 저장소를 사용하며 유효한 기존 본인 로그인은 재사용합니다. 새 기기 코드를 자동 발급하지 않습니다. 사용자의 로그인·업무 자료는 설치 파일에 포함하지 않으며 새 기기에서는 본인이 로그인합니다.

AI 그림은 **연결·관리 → 이미지 요청 준비**에서 설명을 적고 보낼 내용을 미리 본 뒤 **이번 이미지 요청하기**로 요청합니다. 완료 후 **PNG 이미지 내려받기**로 받습니다. 앱에 저장된 그림은 전체 업무 백업에 포함하며 본인 로그인 저장소 전체는 백업하지 않습니다. 원본 사진 업로드·기존 그림 수정·여러 장 생성은 지원하지 않습니다. 그림을 직접 열어 내용·사용 권리를 확인하세요. 로컬 홍보 PNG와 별도의 그림 파일이며 문서에 넣으려면 받은 파일을 편집 프로그램에서 직접 사용합니다.

각 요청의 완료 여부는 실제 결과로 확인합니다. 실패·취소 후 자동 재시도하지 않으며 사용량 복원을 보장하지 않습니다. 텍스트와 이미지 모두 본인 계정의 사용량·한도를 소모할 수 있고 유료 API로 자동 전환하지 않습니다.

업데이트는 서명·고정 공개키·버전·파일 검사를 거쳐 PIN과 직접 적용 확인을 요구합니다. [공식 배포 저장소](https://github.com/hdw727-code/healing-aroma-updates)의 실제 릴리스와 앱의 상태 안내를 확인하세요. 저장소가 있다는 이유만으로 설치·업데이트 파일이 게시됐다고 판단하지 않습니다. 적용 전 전체 업무 백업을 보관하고 적용 후 문서·사본·AI 결과를 다시 확인합니다.

같은 컴퓨터의 백업만으로 기기 고장을 대비할 수 없습니다. 전체 ZIP을 본인이 관리하는 다른 저장장치에도 보관하고 시험 복구합니다. 로그인·관리자 PIN·원본·앱 밖에만 있는 파일은 업무 백업과 따로 관리합니다.
