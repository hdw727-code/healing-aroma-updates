# 아로마 업무 · 1.1.0 처음 설정하기

## 1.0.1 자료를 1.1.0으로 가져오기

1.1.0은 신청·주문, 체험·상품, 일정과 문의 검색·상태별 목록을 포함한 별도 설치본입니다. 기존 1.0.1 업데이트 화면에서 자동 설치되지 않습니다. 이전 앱을 지우거나 덮어쓰지 않습니다.

1. 이전 1.0.1 앱에서 **연결·관리 → 전체 업무 백업·복구 → 전체 백업 만들기 → ZIP 다운로드**로 백업을 준비합니다. 원본 ZIP을 별도 저장장치에도 보관합니다.
2. 1.1.0 설치 ZIP 전체를 새 폴더에 풀고 최상위 `INSTALL.cmd`를 실행합니다. 새 기본 위치는 `%LOCALAPPDATA%\HealingAromaWork_1_1_0`이며 바탕화면의 **아로마 업무 도우미 1.1**로 엽니다. 기존 1.0.1 폴더와 바로가기를 보존합니다.
3. 새 앱에서 본인이 새 관리자 PIN을 정합니다. 이전 PIN·AI 로그인·외부 연동 인증은 가져오지 않습니다. AI를 쓰려면 새 앱에서 본인의 공식 로그인을 별도로 확인합니다.
4. **처음 화면 → 이전 앱 자료 가져오기** 또는 **연결·관리 → 전체 백업·이전 자료 가져오기**에서 이전 ZIP을 선택합니다. **선택한 백업 가져오기**는 검증한 사본만 만들며 현재 업무를 바꾸지 않습니다.
5. 목록에 **이전 자료 형식 · 변환 필요**가 표시되면 **새 형식 사본 만들기**를 누릅니다. 변환은 원본 ZIP을 보존하고 새로운 백업만 만듭니다.
6. 새 사본의 포함 범위를 확인한 뒤 **이 백업으로 복원 → 확인하고 전체 복원**을 선택합니다. 이 단계는 현재 1.1.0 업무를 백업 내용으로 바꾸므로 바꿀 자료를 직접 확인합니다. 복원 전 안전 백업과 자료 사본을 보관하며 새 앱의 PIN은 유지합니다.
7. 문서·사본·AI 결과·출력 파일·프로그램 목록을 열어 비교합니다. 확인을 마칠 때까지 이전 앱과 ZIP을 보관하고 두 앱의 업무를 각각 수정하지 않습니다.

전체 백업의 포함 범위(v1/v2)와 업무 데이터 형식(schema 1/2)은 서로 다른 표시입니다. 이전 포함 범위 v1 백업은 새 형식으로 변환해도 프로그램 설정·자료 목록을 새로 만들지 않으며 현재 설정을 유지합니다. 앱 밖에만 있는 파일과 원본 USB는 따로 보관합니다.

## 신청·주문 사용 범위

**신청·주문**에서 직접 기록한 문의를 접수·확인 중·처리 완료 등의 상태로 관리합니다. 기본 **해야 할 일**은 접수·확인 중이며 예약 취소는 제외합니다. 상태별 건수를 보고 상품·체험 이름이나 문의 번호로 검색합니다. 관리자 잠금을 누르면 검색어와 고객 내용도 화면에서 지웁니다. 실제 예약·금액·재고는 확인해서 입력합니다.

외부 신청 Site 연결은 아직 설정하지 않았습니다. 설치만으로 외부 사이트 문의가 들어오거나 어머니에게 알림이 전송되지 않습니다. 고객 발송·결제·예약 확정도 자동 실행하지 않습니다.

1.1.0용 첫 설정 안내입니다. 설치 파일의 버전·공식 배포 안내를 확인합니다. 컴퓨터마다 설치·본인 로그인·출력·백업 준비를 별도로 확인해야 합니다. 일반 사용은 [MOTHER_GUIDE.html](MOTHER_GUIDE.html), 운영·복구는 [SON_GUIDE.md](SON_GUIDE.md), 전체 안내는 [README.md](README.md), 시작 화면은 [START_HERE.html](START_HERE.html)을 확인합니다.

## 컴퓨터와 첫 실행

Windows 10/11 AMD64(x64: Intel/AMD 64비트)를 대상으로 합니다. Windows 10은 1809/build17763 이상이고 충분히 업데이트된 환경에서 best effort 조건입니다. 어머니 실제 PC·두 OS 전체 기능·프린터 확인은 따로 필요합니다. macOS·32비트·ARM을 지원하지 않습니다.

1. 공식 배포 저장소에 설치 ZIP이 있는지 확인하고 버전·파일 해시·라이선스 안내를 확인합니다.
2. ZIP 전체를 새 폴더에 압축 해제하고 최상위 `INSTALL.cmd`를 실행합니다. 압축 파일 안에서 실행하지 않습니다.
3. 설치 완료 안내를 확인합니다. 기본 위치는 현재 사용자의 `%LOCALAPPDATA%\HealingAromaWork_1_1_0`입니다. 기존 대상이 있으면 설치를 중단하며 자료를 덮어쓰지 않습니다.
4. 바탕화면의 **아로마 업무 도우미 1.1**를 엽니다. 바로가기가 없으면 설치 폴더의 `aroma_app\START_APP.cmd`를 실행합니다.
5. 브라우저 화면과 저장 위치를 확인하고 앱 종료·재실행을 시험합니다. 설치 자체는 앱·로그인·AI·업데이트를 실행하지 않습니다.
6. 빈 프로그램 목록에 본인이 확인한 수업·준비물·단가·세금·일정을 준비합니다.
7. 시험 견적 한 건을 작성 중으로 저장하고 다시 엽니다. 실제 출력과 전체 백업/복구도 시험합니다.

설치는 현재 사용자 범위에서 하며 전역 Python 설치·서비스·영구 보안 정책 변경을 하지 않습니다. 기존 바탕화면 바로가기는 보존하므로 연결 대상이 다른 앱이면 아들과 확인합니다. 설치 중단 시 기존 자료와 실패한 준비 폴더를 지우지 말고 오류 문구를 확인합니다.

공식 실행 파일은 포함한 버전을 사용합니다. 실행 파일이 있어도 계정 로그인·OS 정책·출력 환경의 성공이 보장되지는 않습니다. 차단되면 OS/build와 오류 문구를 확인하며 보안 정책을 우회하거나 자동 설치하지 않습니다. 견적·계획·로컬 저장·서식 출력은 Codex 로그인 없이 사용할 수 있습니다.

## AI 텍스트를 선택할 때

본인의 Codex 이용 가능 계정과 정상 공식 로그인이 필요합니다. 기존 본인 로그인이 유효하면 그대로 재사용합니다. 앱이 새 기기 코드를 자동 발급하지 않습니다. 새 로그인이나 만료 후 재로그인이 필요할 때 사용자가 공식 화면에서 직접 계정·권한을 확인합니다. 앱을 설치하거나 켜는 것만으로 로그인·모델 요청을 실행하지 않습니다. 다른 사람의 인증 파일·token·브라우저 세션을 복사하지 않고 앱이 비밀번호를 받지 않습니다.

이 앱의 로그인 저장은 운영체제 자격증명 저장소를 사용하는 keyring 조건을 따릅니다. 저장소를 사용할 수 없으면 멈추며 평문 파일로 자동 전환하지 않습니다. 다른 컴퓨터의 로그인 완료가 새 기기의 준비 완료를 뜻하지 않습니다. 기기 정책이나 실제 계정 권한은 사용자가 확인해야 합니다. [공식 Codex 인증 안내](https://learn.chatgpt.com/docs/auth)를 참고합니다.

정상 로그인과 실행 환경이 준비돼도 각 AI 요청은 **보낼 항목 선택 → 전체 미리보기 → 이번 동의 → 요청 → 실제 결과 확인**을 거칩니다. 전화번호·이메일 기본 제외와 자료·사진 자동 전송 없음은 유지합니다. 새 API key·유료 서비스로 자동 전환하지 않습니다. 계정 플랜의 사용량·한도를 소모하며 실패·취소해도 사용량 복원을 보장하지 않습니다.

## AI 그림을 요청할 때

홍보 PNG는 글자를 그리는 로컬 서식이며 AI 그림과 별개입니다. **연결·관리 → 이미지 요청 준비**에서 만들 그림의 설명을 적습니다. **보낼 내용 미리보기**를 읽고 이번 전송에 동의한 뒤 **이번 이미지 요청하기**를 누릅니다. 완료 후 **PNG 이미지 내려받기**로 받고 실제 그림을 확인합니다. 참고 사진 업로드·기존 그림 수정·여러 장 생성은 지원하지 않습니다. 그림은 문서에 자동 삽입하지 않으며 받은 파일을 편집 프로그램에서 직접 사용합니다.

이 앱은 다른 개인 설정과 분리하기 위해 앱 전용 환경에서 본인 공식 로그인을 사용합니다. 서비스 자체가 반드시 새 로그인 환경을 요구한다는 뜻은 아닙니다. 유효한 기존 본인 로그인은 재사용합니다. 새 기기에서는 사용자가 이 방식을 이해하고 직접 로그인을 선택해야 합니다. 앱을 켜는 것만으로 새 환경의 로그인이나 기기 코드를 시작하지 않으며 기존 인증을 복사하지 않습니다.

공식 기기 로그인은 본인이 휴대폰 브라우저로 [공식 Codex 기기 인증 주소](https://auth.openai.com/codex/device)에서 계정·기기·요청 권한을 확인하고 일회성 코드를 넣는 방식입니다. 코드는 준비한 시점에 발급하며 표시된 유효시간을 따릅니다. device-code는 beta 기능이고 개인 계정 Security 설정이나 workspace 권한이 필요할 수 있습니다. 사용자가 직접 설정을 확인하며 자동으로 켜거나 새 권한을 승인하지 않습니다. 자세한 절차는 [공식 인증 안내](https://learn.chatgpt.com/docs/auth)에 있습니다.

**이미지 연결 확인**에서 본인 로그인·실행 준비 상태를 확인합니다. 공식 로그인 시작·중단과 실행 준비 확인에는 관리자 PIN과 직접 확인을 거칩니다. 준비 확인은 모델 요청을 하지 않습니다. 로그인 정보는 설치본·업무 백업·공개 파일에 넣지 않습니다. 준비 표시만으로 이번 생성의 성공을 판단하지 말고 실제 결과를 확인하세요. 앱에 저장된 그림 파일은 전체 백업 v2에 포함하지만 본인 로그인 저장소 전체는 포함하지 않습니다. 자동 재시도·확인되지 않은 도구·유료 API 전환은 없습니다.

## 저장·전체 백업·PIN

관리자 PIN은 처음 설정할 때 본인이 정하고 안전하게 기억합니다. 현재 PC에 보관되며 앱을 다시 켜도 유지합니다. 공개 안내·로그·브라우저 임시 저장소에 PIN을 적지 않습니다. PIN은 로컬 관리자 기능의 확인이며 인터넷 계정이나 원격 권한이 아닙니다.

새 전체 백업 v2는 문서 DB·사본·AI 결과·앱 출력물/PNG·현재 프로그램 설정·자료 목록을 포함합니다. 이전 v1 전체 백업은 현재 프로그램 설정을 유지하고 업무 파일만 복구합니다. 목록의 형식·포함 표시를 확인합니다. 예전 문서·설정 백업은 실제 사본 파일을 포함하지 않습니다. 기본 압축 전 한도는 1 GiB·10,000개입니다.

관리자 PIN·로그인·로그·이전 백업·코드·원본·앱 밖에만 있는 파일은 전체 업무 ZIP에서 제외합니다. 현재 PIN은 복구 후 유지하고 공식 로그인은 따로 확인합니다. 다른 저장장치에도 ZIP을 보관하고 시험 폴더에서 실제 복구·문서/사본/AI/출력/프로그램 비교를 마칩니다.

다른 장치의 전체 백업 ZIP은 전체 백업 화면에서 파일을 선택해 가져옵니다. 원본은 보존하며 이전 자료 형식이면 새 형식 사본을 만든 뒤 별도로 복원합니다.

## 멈췄을 때와 업데이트

복구 완료를 확인하지 못했다면 같은 복구를 반복하거나 잠금 파일을 지우지 않습니다. 자료·안전 백업을 보존하고 앱 종료 확인 뒤 다시 켭니다. 중단 복구는 PIN과 직접 확인을 거치며 이전 실행의 종료를 모르면 먼저 확인합니다.

인터넷 업데이트는 **연결·관리 → 앱 업데이트 확인**에서 실제 공개 릴리스를 확인합니다. 업데이트 확인→변경 검토→PIN→직접 적용 확인→실제 상태 재접속을 따릅니다. 적용 전에 전체 업무 백업을 보관합니다. 요청 응답이 끊기면 상태를 조회하며 자동 재적용하지 않습니다. 설치/업데이트 공개 파일에는 사용자 자료·로그인·개인키를 넣지 않습니다. [공식 배포 저장소](https://github.com/hdw727-code/healing-aroma-updates)에 실제 릴리스가 있는지 확인하고 검증하지 않은 링크로 설치하지 않습니다.

## 직접 확인할 완료 기준

- 도움 없이 시험 견적을 저장하고 다시 열 수 있습니다.
- 실제 프로그램·금액·날짜·세금과 ‘확인 필요’ 표시가 출력에서도 맞습니다.
- DOCX·PPTX·PNG를 실제 편집기/프린터로 확인합니다.
- 전체 ZIP을 독립 장치에 보관하고 시험 복구합니다.
- AI를 쓸 때 본인 로그인·보낼 내용·이번 동의·한도·실패 대응을 이해합니다.
- 이미지·새 설치·원격 업데이트는 각각 실제 확인 전까지 완료로 표시하지 않습니다.
