# Aroma Work Helper

Windows x64 app source and verified release downloads. The initial catalog is empty. Personal business data and login credentials stay on the user's PC.

Version 1.1.0 adds the inquiry inbox and uses a separate install folder. Version 1.0.1 users must install 1.1.0 and explicitly import a whole backup; the old same-schema updater cannot apply schema 2.

See [releases](https://github.com/hdw727-code/healing-aroma-updates/releases) and [the guide](aroma_app/README.md). Manifests use the independently installed P-256 publisher pin.
