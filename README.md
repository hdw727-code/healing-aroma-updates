# Aroma Work Helper

Windows x64 app source and verified release downloads. The initial catalog is empty. Personal business data and login credentials stay on the user's PC.

See [releases](https://github.com/hdw727-code/healing-aroma-updates/releases) for installation and [the guide](aroma_app/README.md).
Release manifests use the independently installed P-256 publisher pin; Git commits are not signed with that key.
